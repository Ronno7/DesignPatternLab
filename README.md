# DesignPatternLab
A Unity project implementing design patterns from David Baron’s Game Development Patterns with Unity.  
## Demo Here: https://ronno7.github.io/DesignPatternLab/

Chapter 11 adds Strategy-pattern drone maneuvers to the existing pooled drones.
Open `DesignPatternLab/` in Unity and play the `Main` scene.

See [Chapter 11 setup and testing](Docs/Chapters/Chapter11.md) for drone controls and book adaptations, and [Chapter 10](Docs/Chapters/Chapter10.md) for Visitor-pattern power-ups.
